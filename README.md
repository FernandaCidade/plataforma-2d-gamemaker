# 🟢 Plataforma 2D (GameMaker)

Jogo de plataforma 2D desenvolvido em **GameMaker** com **GML** (GameMaker Language). O projeto faz parte dos meus estudos de programação de jogos e foi criado para praticar a lógica de gameplay de um platformer: movimentação, colisões e interação com o cenário.

## ▶️ Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/FernandaCidade/plataforma-2d-gamemaker.git
   ```
2. Abra o GameMaker e escolha **Open**.
3. Selecione o arquivo `.yyp` na pasta do projeto.
4. Clique em **Run** (ou pressione `F5`) para jogar.

## 📁 Estrutura do projeto

Projetos do GameMaker são organizados em recursos (assets), que aparecem na árvore do editor:

- `objects/`: objetos do jogo (jogador, inimigos, blocos, etc.) e seus eventos em GML
- `rooms/`: fases e salas
- `sprites/`: imagens e animações
- `scripts/`: funções reutilizáveis em GML
